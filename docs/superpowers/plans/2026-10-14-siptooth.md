# Siptooth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `siptooth`, a Go daemon for a Raspberry Pi 5 that answers an Android phone's calls over Bluetooth HFP only after forwarding them to a SIP target answers, and bridges CVSD 8 kHz audio to G.711 RTP.

**Architecture:** Allochka's hardware packages (`bluez`, `hfp`, `sco`, daemon glue, `doctor`, `host`, `cli` skeleton, `hooks`, `control`) are copied and trimmed. New packages: `g711`, `placeholder`, `stun`, `nat`, `sdp`, `rtp`, `sip` (sipgo wrapper), `bridge` (coordinator + media pump). One coordinator goroutine owns call state; everything reaches it as messages; timers come from an injected clock.

**Tech Stack:** Go 1.24 (`go 1.24.0` directive, developer machine has 1.26), CGO off, `github.com/emiago/sipgo v1.6.0`, `github.com/pion/rtp v1.10.5`, `github.com/pion/srtp/v3 v3.1.3`, `github.com/godbus/dbus/v5`, `golang.org/x/sys`, `gopkg.in/yaml.v3`.

**Spec:** `docs/superpowers/specs/2026-10-14-siptooth-design.md` (authoritative; every task cites its sections). **Predecessor source:** `~/Projects/Personal/allochka` (read-only; copy from it, never modify it).

## Review Focus

1. **A `2xx` that crosses CANCEL, or a second forked `2xx`** — must be ACKed and BYEd, never left ringing at the far end (Task 10 tests `TestDialCancelCrossing200`, `TestDialForkedSecond200`).
2. **The owner answers the handset while siptooth is dialing or answering** — siptooth must never send `AT+CHUP` for a call it did not answer (Task 16 tests `TestOwnerAnswersWhileDialing`, `TestOwnerAnswersAfterATAError`).
3. **Audio arriving before the phone's SCO link is up** (ElevenLabs greets immediately) — no speech sample may be dropped; latency recovers only by skipping silence (Task 8 `TestStartupBufferKeepsEverything`, `TestCatchUpSkipsOnlySilence`).
4. **SCO drops mid-call while the cellular call continues (owner moved audio to the handset)** — BYE only, no `AT+CHUP` (Task 16 `TestSCOLossNoCHUP`).
5. **Withheld caller ID / odd characters in `+CLIP`** — `{caller}` becomes `anonymous`, `#` is percent-encoded in URI user parts, CR/LF can never reach a header (Task 4 `TestExpandEscaping`, Task 16 `TestWithheldCaller`).
